# TanksMultiplayerPrototype

Мультиплеерный прототип «танчиков» на Photon PUN 2. Тестовое задание, сделано за 3 дня в августе 2023: до него с сетевым кодом я не работал.

## Как запустить

1. Unity 2021.3.9f1. Photon PUN 2 уже лежит в проекте, AppId прописан в `PhotonServerSettings`.
2. Открыть сцену `Assets/Scenes/Lobby.unity`, нажать Play.
3. Для второго игрока нужен ещё один клиент: сборка под Android или клон проекта через ParrelSync (есть в проекте).

Управление — экранный джойстик: танк едет и стреляет в сторону наклона.

## Что реализовано

- **Лобби.** Подключение к Photon, смена ника, создание комнаты, список комнат с обновлением, вход в комнату.
- **Комната ожидания.** Список игроков, выход из комнаты, кнопка старта только у хоста. Сцена боя загружается у всех через `PhotonNetwork.LoadLevel`.
- **Бой.** Каждый клиент спавнит свой танк в случайной точке экрана. Движение синхронизируется через `PhotonView`, выстрелы создаются через `PhotonNetwork.Instantiate`.
- **Монеты.** Появляются по таймеру из пула, подбор и счёт рассылаются всем через RPC.
- **Здоровье и финал.** Урон и смерть идут через RPC, погибший переводится в команду `Dead` (`PhotonTeamsManager`). Когда в бою остаётся один игрок, всем показывается экран с его ником и числом монет.

## Что упрощено

- состояние (здоровье, монеты, видимость объектов) рассылается буферизованными RPC, а не через `IPunObservable`;
- попадание считает клиент-владелец пули, авторитетного хоста нет;
- переподключения и обработки выхода игрока посреди боя нет;
- объекты сцены находят друг друга через `FindObjectOfType`;
- MVP выдержан только для игрока (`Assets/Scripts/MVP`), лобби написано напрямую на колбэках Photon.
